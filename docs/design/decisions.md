# Решения и открытые вопросы

## Принятые решения

| Решение | Почему |
|---|---|
| Палитра «Фуксия»: тёплый графит + малиново-розовый акцент (OKLCH h 352) | Единственная зона цветового круга без игровых цветов (между Corrupted и Magic/Crafted). Акцент не путается с Rare, Currency, Unique |
| Шрифты Inter + JetBrains Mono | Лучшая читаемость на мелких кеглях и при масштабе Windows 100–200%; OFL, кириллица, табличные цифры; не похожи на игровые |
| Иконки Lucide | ISC-лицензия, единая обводка 2 px, большой набор, пакеты под любой фреймворк |
| Нейтральная шкала построена в OKLCH | Шаги равномерны по воспринимаемой яркости — светлую тему можно получить разворотом шкалы |
| `game.rarity.unique` #AF6025 → #D07940, `game.state.corrupted` #D20000 → #F3413C | Исходные цвета дают 4.1 и 3.4 на нашем фоне. Исходники сохранены в `game.raw.*` |
| Фон оверлея 94% + blur 16 px | При 86% над светлой локацией вторичный текст падает ниже AA |
| `status.danger` — коралл, `status.info` — нейтральный | Красный занят Corrupted, синие — Magic/Crafted/Divination. Статусы отличаются иконкой |
| Текст модов — нейтральный, а не синий как в игре | Синий в UI означает Magic; цвет получают только crafted и fractured |
| Prefix — залитый квадрат, Suffix — контурный круг | Различимы без цвета |
| Раскладка окна — вариант A «Рабочее место» | Выбор заказчика. Лучше растёт до 15 модулей, ниже порог входа |
| Сайдбар 256 px, сворачивается до 64 px | Русские подписи до ~22 символов помещаются без обрезки |
| Окно без прокрутки; большие списки — постранично | Требование заказчика |
| Ассистент крафта ведёт свои попытки отдельно от «текущего предмета» | Крафтится другой предмет, чем последний проверенный; связь — кнопкой «Взять текущий предмет» |
| Никаких элементов автоматизации | Правила игры: одна клавиша — одно действие |

## Открытые вопросы

1. **Игровые цвета не сверены по скриншотам.** Значения взяты из общих данных сообщества. Нужно 3–4 скриншота подсказок предметов из клиента, чтобы сверить, особенно `game.socket.*`.
2. **Цвета implicit / enchant / mirrored.** В системе пока только текстовые теги нейтрального цвета. Если хочется игровых цветов — добавить в `game.mod.*` и проверить контраст.
3. **Светлая тема** не рисовалась — только заложена (семантика поверх примитивов).
4. **Расширение браузера** (боковая панель на pathofexile.com/trade) по этой системе ещё не проверялось — рекомендуется компактная плотность и `color.bg.surface` как фон панели.
5. **Компактный режим окна** (узкое окно поверх игры) не входит в выбранный вариант; модули его поддерживают (свойство `compact` в макетах), если понадобится позже.
6. **Горячие клавиши** в макетах условные: `Ctrl+D`, `Ctrl+K`. Нужно проверить конфликты с клавишами игры и с Awakened PoE Trade.
7. **Иконки валют и предметов** в макетах — заглушки. Нужен источник картинок и лицензионная проверка их использования.
