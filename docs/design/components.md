# Компоненты

Обозначения: токены пишутся без `--` и в точечной форме (`color.bg.hover` = `var(--color-bg-hover)`). Размеры, отмеченные `size.*`, автоматически переключаются в компактной плотности (`data-density="compact"`).

## Общие правила состояний

| Состояние | Правило |
|---|---|
| default | как в спецификации компонента |
| hover | фон на шаг выше (`bg.surface → bg.hover`, прозрачный → `bg.hover`); для `accent.solid` → `accent.solid-hover`. Курсор `pointer` |
| active (pressed) | `bg.active`; для акцента → `accent.solid-active` |
| focus-visible | `outline: border-width.focus solid color.border.focus; outline-offset: 2px`. Только с клавиатуры (`:focus-visible`) |
| disabled | текст `text.disabled`, рамка `border.subtle`, фон без изменений, `cursor: default`. **Без opacity** |
| selected | фон `bg.selected`, текст `text.primary` + `semibold`, иконка `icon.accent` |

Переходы: `motion.duration.fast` + `motion.easing.standard`, только `background-color`, `color`, `border-color`.

Минимальная зона клика в основном окне — 28 px по высоте, в оверлее — 28 px. Все интерактивные элементы — настоящие `<button>`, `<a>`, `<input>`, у кнопок-иконок обязательный `aria-label`.

## 1. Кнопки

| Вариант | Фон | Текст | Рамка |
|---|---|---|---|
| primary | `accent.solid` | `text.on-accent`, semibold | нет |
| secondary | `bg.hover` | `text.primary`, medium | 1px `border.strong` |
| ghost | прозрачный | `text.accent`, medium | нет |
| danger-ghost (удаление) | прозрачный | `status.danger.fg` | нет |

- Высота `size.control-height` (32 / 28), горизонтальный отступ `space.3` (12), радиус `radius.md`, шрифт `font.size.body` (14) / `label` (13) в compact.
- Иконка 16 px слева, зазор `space.1-5` (6).
- **Кнопка-иконка:** квадрат `size.control-height`, иконка 16, фон прозрачный, цвет `icon.default`; hover — `bg.hover`. Обязателен `aria-label` и подсказка (tooltip).
- В одной группе — не больше одной primary.

## 2. Поля ввода

- **Поле:** высота `size.control-height`, фон `bg.surface`, рамка 1px `border.strong`, радиус `radius.md`, отступ `space.2-5`, текст `body`, плейсхолдер `text.secondary`. Hover — рамка `text.disabled`; focus — рамка `border.focus` + кольцо фокуса; ошибка — рамка `status.danger.fg` + текст ошибки под полем 13 px `status.danger.fg` с иконкой.
- **Поиск:** поле + иконка лупы 16 px слева (`icon.default`), справа — кнопка очистки (появляется при вводе).
- **Выпадающий список (select):** как поле + шеврон 14 px справа. Меню — см. «Контекстное меню».
- **Поле горячей клавиши:** как поле, значение — набор чипов клавиш (п. 11); в режиме записи — рамка `border.focus` и текст «Нажмите сочетание…».
- **Чекбокс:** 16×16, радиус `radius.xs`, рамка `border.strong`; вкл. — фон `accent.solid`, галочка `text.on-accent`. Подпись справа, зазор 8, клик по подписи переключает.
- **Радио:** 16×16 круг, рамка `border.strong`; вкл. — рамка `accent.solid` + точка 8 px `accent.solid`.
- **Переключатель (switch):** трек 32×18 (compact 28×16), радиус `radius.full`; выкл. — трек `bg.active`, бегунок `text.secondary`; вкл. — трек `accent.solid`, бегунок `text.on-accent`. Подпись справа.
- **Слайдер:** трек 4 px `bg.active`, заполненная часть `accent.solid`, бегунок 14 px `text.primary` с рамкой `accent.solid`; значение — моно справа.

## 3. Вкладки и сегменты

- **Вкладки:** текст `body`, `text.secondary`; активная — `text.primary` semibold + подчёркивание 2 px `accent.solid`. Отступ между вкладками `space.5`.
- **Сегментированный переключатель:** контейнер `bg.raised`, рамка `border.default`, внутренний отступ 2, радиус `radius.md`; сегмент высотой `size.control-height − 4`, радиус `radius.sm`, текст `label` medium `text.secondary`; активный — фон `bg.active`, текст `text.primary`.

## 4. Всплывающие элементы

- **Подсказка (tooltip):** фон `bg.active`, рамка `border.strong`, радиус `radius.md`, текст 13 px `text.primary`, отступ 6×10, тень `shadow.popover`, `z.tooltip`. Задержка 400 мс, появление `motion.duration.fast`.
- **Поповер:** фон `bg.raised`, рамка `border.strong`, радиус `radius.xl`, отступ `space.4`, тень `shadow.popover`, `z.popover`.
- **Контекстное меню / меню списка:** как поповер, отступ 6; пункт высотой `size.row-height`, радиус `radius.md`, иконка 16 `icon.default`, текст `body`, справа — подсказка клавиши `caption` `text.muted`. Подсвеченный пункт — `bg.active`. Заголовок группы — 12 px, semibold, капс, разрядка 0.06em, `text.muted`.

## 5. Бейджи и теги

Все бейджи: шрифт 13 px (12 допустимо только в основном окне), высота строки 18, радиус `radius.sm`, отступ 0×6. **Всегда содержат текст.**

| Бейдж | Вид |
|---|---|
| Редкость | Текст `NORMAL / MAGIC / RARE / UNIQUE / GEM / CURRENCY / DIVINATION`, bold, капс, разрядка 0.06em. Рамка 1px и текст — `game.rarity.*`, фон прозрачный |
| Тип мода | Текст `crafted / fractured / implicit / enchant`, semibold, строчные. crafted — рамка **пунктиром** `game.mod.crafted`; fractured — сплошная `game.mod.fractured`; implicit / enchant — `border.default` + `text.secondary` |
| Prefix | `P` моно semibold, квадрат 20×20, **залит** `border.default`, радиус `radius.sm` |
| Suffix | `S` моно semibold, круг 18×18, **контур** 1px `text.secondary`. Форма отличает от префикса без цвета |
| Тир | `T1…T9` моно semibold, рамка 1px. T1 — рамка и текст `text.accent`; остальные — рамка `border.default`, текст `text.secondary`; нет тира — `—` `text.muted` |
| Состояние предмета | `◆ CORRUPTED` — рамка и текст `game.state.corrupted`, фон этого цвета 12%. `MIRRORED`, `SPLIT`, `UNIDENTIFIED` — рамка `border.strong`, текст `text.primary` |
| Тег-фильтр (чип) | высота 28, радиус `radius.full`, рамка `border.default`, текст `label`; выбран — рамка `accent.solid`, фон `accent.subtle`, текст `text.accent` |

## 6. Строка мода

```
[P] +105 (100–109) to maximum Energy Shield            [T1]
```

- Сетка: бейдж affix (20) · текст (1fr) · бейдж тира (min 26). Зазор `space.2-5`, выравнивание по первой строке (`align-items: flex-start`), перенос текста разрешён.
- Текст `body` / line-height 20, цвет `text.primary` (crafted — `game.mod.crafted`, fractured — `game.mod.fractured`).
- Значение — моно semibold; диапазон — моно `text.secondary` в скобках, en dash: `(100–109)`.
- Перед текстом crafted/fractured — тег типа мода.
- Расстояние между строками `space.2` (8).

## 7. Отображение цены

- **Основная:** `~120` моно semibold (`font.size.number-xl` 36 в Price check, `number-lg` 20–22 в оверлее и панелях) + иконка валюты 18–24 px + название валюты `text.primary`/`secondary`.
- **Пересчёт:** `≈ 0.6 divine` моно `text.secondary`.
- **Диапазон:** `105 c — 0.7 div`, моно, тире с пробелами.
- **Знаки:** `~` — оценка, `≈` — пересчёт, без знака — точная цена лота.
- Иконка валюты — картинка из игры 1:1 с `alt`/`aria-label` (`Chaos Orb`). Пока картинок нет — круг с буквой цветом `game.rarity.currency`.
- Свежесть данных — тег рядом: `✓ данные свежие · 2 мин` (`status.success`) или `▲ старше часа` (`status.warning`).
- **Валюта показа** (выбор в шапке, п. 17а; план — `shared/docs/price-currency.md`): рыночные цены хранятся в chaos и показываются через `MarketPrice` — валюту выбирают режим и курс divine лиги из `PriceDisplayProvider`. Режимы: «Авто» (до 1 divine — chaos, дороже — divine), «Chaos», «Divine» (мелочь честно: `0.014 divine`), «Обе» (основная по правилу «Авто» + пересчёт). Без курса — chaos. Строкой (подсказки, `title`) — `usePriceText()`: `120 c`, `1.25 div`, `1.25 div (250 c)`. Точные цены лотов — в валюте продавца через `Price`, не переводятся. В плотных таблицах — `compact` (без пересчёта). График истории — в валюте основной цены; в divine каждая точка делится на курс divine на тот же момент (`usePriceHistoryIn`), подпись шкалы — `divine`.
- **Числа:** меньше 1 — две значащие цифры (`0.014`, `0.35`), 1–10 — до двух знаков, от 10 — целые.

## 8. Списки и таблицы

- **Строка списка:** высота `size.row-height`, отступ `size.padding-x`, разделитель 1px `border.subtle`; hover — `bg.hover`; выбранная — `bg.selected`.
- **Таблица (плотная):** шапка — фон `bg.raised`, текст `label` `text.secondary`; строки высотой `size.table-row-height`, текст 13 px; числа — моно, выравнивание по правому краю. Сортируемая колонка: заголовок кликабельный, стрелка `↑`/`↓` после названия, активная колонка — `text.primary`. Строки не зебрить — только разделители `border.subtle`.
- **Постраничный вывод (вместо прокрутки):** слева «`1–11 из 11`» (`label`, числа моно), справа кнопки-иконки ‹ › и номера страниц (32×32, текущая — рамка `accent.solid`, фон `accent.subtle`, текст `text.accent`). Число элементов на странице считается от доступной высоты.

## 13. Уведомления

- **Тост:** справа снизу над строкой статусов, ширина 360, фон `bg.raised`, рамка `status.*.border`, иконка и заголовок цвета `status.*.fg`, текст `text.primary`, тень `shadow.popover`, `z.toast`. Появление `motion.duration.slow`, автоскрытие 5 с (кроме danger).
- **Баннер:** во всю ширину области модуля, фон `status.*.bg`, рамка `status.*.border`, радиус `radius.lg`, иконка 20, заголовок `body` semibold `status.*.fg`, пояснение `label` `text.primary`, действия справа (secondary + ghost).

## 14. Пустое состояние, загрузка, ошибка

- **Пусто:** по центру области: иконка 32 `icon.default`, заголовок `body-lg` semibold, пояснение `body` `text.secondary`, одна кнопка или подсказка клавиши («Наведите на предмет в игре и нажмите `Ctrl + D`»).
- **Загрузка:** скелетоны — прямоугольники `bg.hover` с радиусом элемента, плавная пульсация opacity 0.6↔1 за 1.2 с. Скелетон повторяет раскладку будущего контента (строки модов, цена).
- **Ошибка:** баннер danger (п. 13) с действием «Повторить».

## 15. Скроллбар
