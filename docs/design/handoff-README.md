# poe-manager — дизайн-система (передача в разработку)

Набор для реализации UI десктопного приложения poe-manager (Electron), его оверлея поверх Path of Exile 1 и, позже, расширения браузера. Тёмная тема, палитра «Фуксия», шрифты Inter + JetBrains Mono. Раскладка окна — вариант A «Рабочее место».

## Что внутри

| Путь | Что это | Когда читать |
|---|---|---|
| `tokens/tokens.json` | Токены в формате W3C Design Tokens. **Источник истины.** | Перед любой вёрсткой |
| `tokens/tokens.css` | Те же токены как CSS-переменные (`color.bg.app` → `--color-bg-app`). Сгенерирован из JSON | Подключить первым стилем |
| `tools/build_tokens.py` | Скрипт, который собирает оба файла токенов из одного описания | Если меняете токены |
| `docs/guide.md` | Правила: какие токены где, игровые цвета, оверлей, запреты | Обязательно, первым |
| `docs/components.md` | Спецификация компонентов: размеры, состояния, токены | При реализации компонентов |
| `docs/app-shell.md` | Раскладка главного окна (вариант A), экраны, оверлей, поведение | При сборке окна и модулей |
| `docs/contrast.md` | Таблица контрастов ключевых пар | При сомнениях в цвете текста |
| `docs/decisions.md` | Принятые решения и открытые вопросы | Перед тем как «улучшать» |
| `reference/mockups/` | Исходники макетов (HTML) — эталон вида и данных | Для сверки результата |

## Порядок работы для агента

1. Подключить шрифты офлайн (см. ниже) и `tokens/tokens.css`.
2. Прочитать `docs/guide.md` целиком — там жёсткие правила.
3. Реализовать компоненты по `docs/components.md`. Никаких «сырых» цветов, размеров и теней в коде компонентов: только `var(--…)`. Если токена не хватает — добавить его в `tools/build_tokens.py`, пересобрать оба файла, а не хардкодить.
4. Собрать окно по `docs/app-shell.md` и сверить с `reference/mockups/`.

## Зависимости (все с открытыми лицензиями, работают офлайн)

```bash
npm i @fontsource-variable/inter @fontsource-variable/jetbrains-mono lucide
```

```css
@import "@fontsource-variable/inter";
@import "@fontsource-variable/jetbrains-mono";
@import "./tokens/tokens.css";
```

- **Inter** и **JetBrains Mono** — SIL OFL 1.1, кириллица есть. Имена семейств в токенах уже совпадают с `@fontsource-variable` (`"Inter Variable"`, `"JetBrains Mono Variable"`).
- **Lucide** — набор UI-иконок (ISC). Обводка 2 px, размер 16 или 18 px, цвет — `currentColor`. Пакет зависит от фреймворка (`lucide`, `lucide-react`, `lucide-vue-next`…) — берите тот, что подходит выбранному стеку.
- Иконки предметов игры — отдельная история: PNG из игры, вставляются в рамку иконки (см. `components.md`).

## Пересборка токенов

```bash
python3 tools/build_tokens.py tokens
```

UI-фреймворк дизайн-система не навязывает: всё описано через CSS-переменные и HTML-семантику.
