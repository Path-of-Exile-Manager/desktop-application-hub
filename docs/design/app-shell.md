# Оболочка приложения — вариант A «Рабочее место»

Полноценное окно для второго монитора: модули слева, работа в центре, текущий предмет справа, статусы внизу. Поверх игры — только виджет оверлея у курсора.

## Раскладка

```
┌──────────────────────────────── titlebar 40 ─────────────────────────────────┐
│ logo · лига              [ Поиск предметов, модулей и команд  Ctrl K ]   _ □ × │
├────────────┬─────────────────────────────────────────────┬───────────────────┤
│ sidebar    │ модуль                                      │ текущий предмет   │
│ 256 / 64   │ flex: 1, padding 20×28                      │ 300               │
│            │                                             │                   │
├────────────┴─────────────────────────────────────────────┴───────────────────┤
│ ● Игра найдена  ● Данные 3.29.3.3 · актуальны  ● Расширение   statusbar 28   │
└──────────────────────────────────────────────────────────────────────────────┘
```

| Область | Размер | Токен |
|---|---|---|
| Окно по умолчанию | 1440×900 | `layout.window.default-*` |
| Минимум окна | 1280×720 | `layout.window.min-*` |
| Шапка | 40 | `layout.titlebar.height` |
| Сайдбар | 256, свёрнутый 64 | `layout.sidebar.*` |
| Правая панель | 300, скрываемая | `layout.panel.width` |
| Строка статусов | 28 | `layout.statusbar.height` |
| Отступы модуля | 20×28 | `size.page-padding-*` |

Доступная область модуля: 1440×900 → ≈ 884×832; 1280×720 → ≈ 724×652 (больше при свёрнутом сайдбаре или скрытой панели).

## Главное правило: без прокрутки

**Ни одна область окна не прокручивается.** Всё содержимое модуля помещается в окно 1440×900 без уменьшения шрифтов, и должно помещаться на 1280×720.

Как добиваться:

1. Колонки модуля переносятся (`flex-wrap`) только если не помещаются по ширине — базовые ширины колонок подобраны так, чтобы при 724 px они ещё стояли рядом (Price check: 360 + 280; крафт: 300 + 300).
2. Большие наборы данных (справочник, история, закладки, похожие лоты) — **постранично**: число элементов на странице = сколько помещается в доступную высоту (считать через `ResizeObserver`). Компонент пагинации — `components.md`, п. 8.
3. Длинные тексты в узких местах (панель «Текущий предмет») — одна строка с многоточием и полным текстом в `title`. В навигации многоточие запрещено — подписи короткие.
4. Прокрутка допустима только внутри выпадающих меню и модальных окон.
5. При сворачивании сайдбара и скрытии правой панели модуль получает место; при ширине окна < 1360 правую панель можно скрывать автоматически.

## Сквозные элементы

- **Навигация:** группы «Проверка» (Price check, История), «Крафт» (Ассистент крафта, Harvest, Карты), «Данные» (Справочник, Закладки); внизу «Настройки» и «Свернуть панель». Должна выдерживать 10–15 модулей: при нехватке высоты группы сворачиваются, а не прокручиваются.
- **Текущий предмет:** последний пойманный предмет, общий для всех модулей. Правая панель со сводкой и действием «Передать в модуль».
- **Лига:** в шапке, глобальная настройка, влияет на цены.
- **Ctrl+K:** палитра поиска модулей, предметов и команд.
- **Статусы:** окно игры, данные, расширение браузера. Отвечают на вопрос «почему не работает».

## Модули

### Price check
Заголовок модуля + действия (ghost «В закладки», secondary «В ассистент крафта», primary «Искать на сайте торговли»). Ниже две колонки: карточка предмета (редкость, имя, база, iLvl, качество, ES, сокеты, моды, состояние) и колонка цены (оценка, пересчёт, «23 похожих», свежесть) + таблица похожих лотов (5 строк, остальное — по клику на сайт торговли).

### Ассистент крафта
Только расчёт и подсказки. Сверху — вердикт («Продолжай · шаг 2» / «Цель достигнута»). Слева — цель (условия с ✓/✗) и последняя проверка; справа — план из шагов с шансом, ценой попытки и ожидаемым числом попыток, итог. Внизу — напоминание: «Ассистент ничего не нажимает в игре: одна клавиша — одно ваше действие».
Ассистент ведёт свои попытки отдельно от глобального текущего предмета; текущий предмет можно взять основой кнопкой «Взять текущий предмет».

### Справочник
Поиск, сегменты «Все / Обычные / Уникальные», переключатель «Только продаваемое», чипы классов. Сетка плиток (`minmax(128px, 1fr)`) с рамками иконок по сетке инвентаря; внизу пагинация.

## Оверлей

- Отдельное окно Electron: прозрачное, без рамки, `alwaysOnTop`, не забирает фокус у игры, не попадает в Alt+Tab.
- Появляется рядом с курсором по `Ctrl + D` мгновенно, прячется по `Esc`, клику мимо или уходу курсора; можно закрепить.
- Содержимое — `OvA.dc.html`: шапка 36, редкость + имя + база + свойства, 6 строк модов, состояние + цена, подвал «Подробнее в окне» / «В ассистент крафта».
- Ширина 440, не выходит за край экрана.

## Горячие клавиши (условные, настраиваются)

`Ctrl + D` — проверить предмет под курсором · `Ctrl + K` — поиск и команды · `Esc` — закрыть оверлей / палитру.

## Реализационные заметки

- Шапка окна — своя (`frame: false`), зона перетаскивания через `-webkit-app-region`.
- Состояния «свёрнут сайдбар», «скрыта правая панель», размер окна — сохранять между запусками.
- Все тексты — через i18n: интерфейс RU/EN, игровые названия и моды — как в клиенте игры (EN в макетах). Русские строки длиннее — проверять обе локали на 1280×720.
